## As três ferramentas em uma frase

- **Claude Code**: o assistente de IA no terminal da Anthropic; lembra do seu projeto com o CLAUDE.md e se comporta com os modos de permissão.
- **Codex CLI**: o agente no terminal da OpenAI; sandbox e aprovação separados, e o `codex exec` é perfeito para scripts e CI.
- **Cursor**: a IDE nativa de IA; `Cmd+K` edita inline, `Cmd+L` pergunta, `Cmd+I` deixa o Agent fazer tudo.
