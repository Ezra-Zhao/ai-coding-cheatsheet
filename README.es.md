## Las tres herramientas en una frase

- **Claude Code**: el asistente de IA en la terminal de Anthropic; recuerda tu proyecto con CLAUDE.md y se porta bien con los modos de permiso.
- **Codex CLI**: el agente en la terminal de OpenAI; sandbox y aprobación por separado, y `codex exec` es ideal para scripts y CI.
- **Cursor**: el IDE nativo de IA; `Cmd+K` edita en línea, `Cmd+L` pregunta, `Cmd+I` deja que el Agent lo haga todo.
