## 三个工具一句话定位

- **Claude Code**：Anthropic 出品的终端 AI 编程助手，靠 CLAUDE.md 记住项目、靠权限模式管住手脚。
- **Codex CLI**：OpenAI 出品的终端智能体，沙盒和审批分开管，`codex exec` 最适合脚本和 CI。
- **Cursor**：AI 原生 IDE，`Cmd+K` 行内改、`Cmd+L` 问、`Cmd+I` 让 Agent 全自动干活。
